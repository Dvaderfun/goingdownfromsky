# RAIN / PAIN — аркадна збірка 0.2.1

Збережена production-версія до додавання ragdoll/крові. Лише шляхи assets зроблено відносними, щоб збірку можна було відкрити всередині поточного локального сервера: `http://127.0.0.1:5173/releases/arcade-0.2.1/`.

Ця версія має попередній аркадний фінал, парні руки людей у вікнах, оцінки й ризикові краплі. Джерельний код нової гри продовжує підтримувати той самий аркадний режим за замовчуванням.
