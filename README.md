# RAIN / PAIN

[Грати на GitHub Pages](https://dvaderfun.github.io/goingdownfromsky/) · [Аркада 0.2.1](https://dvaderfun.github.io/goingdownfromsky/releases/arcade-0.2.1/)

Нічна браузерна аркада на Three.js. Дівчина в жовтому дощовику падає вздовж фасаду, ухиляється від рук із вікон і збирає краплі. Звичайний успіх відкриває наступну будівлю. Фінал:

> На вулиці rain — на душі pain

Версія 0.5.0 додає ритмічні комбінації хвиль із перепочинками, п'ять кварталів, чесне нарахування близьких прольотів і цілі стилю. «Дощ дня» пропонує одну відтворювану вежу на київську дату з окремим локальним рекордом. Повтор відтворює той самий маршрут. Пізні вежі обмежені 720 м.

Кожна спроба починається короткою сценою на даху: героїня стоїть, наближається до краю й стрибає у місто. Через 3,2 секунди починається керований політ; сцену можна пропустити кнопкою або Space. Пауза зберігає її поточний кадр. У меню можна вибрати аркадний фінал зі спалахом і кільцями або жорсткий ragdoll-фінал із кров’ю. Аркадний режим лишається стандартним, вибір фіксується на початку спроби.

Кожне небезпечне вікно належить одній видимій людині — з головою, торсом і двома анатомічно дзеркальними руками. Обидві руки діють разом і тягнуться до спільної цілі. Збережені рука-переслідувач, ризикові краплі, оцінки C / B / A / S та рекорди відкритих веж.

## Запуск

Потрібні Node.js 20.19+ або 22.12+, npm і сучасний браузер із WebGL 2. Рекомендовано Chrome або Edge з апаратним прискоренням.

```sh
npm install
npm run dev
```

Відкрий адресу, яку надрукує Vite; зазвичай це `http://127.0.0.1:5173`. Гру слід відкривати через HTTP, а не подвійним кліком на `index.html`.

```sh
npm run build
npm run preview
```

Готова вебзбірка — у `dist/`. Звук починається після натискання ігрової кнопки. Загальний рекорд, рекорди й найкращі оцінки веж, денні рекорди, відкритий рівень і налаштування зберігаються в цьому браузері. Денна спроба має окремий рекорд і не відкриває звичайних веж. Збереження попередньої версії сумісні; історичні оцінки збережені.

Попередню production-аркаду 0.2.1 збережено окремо. Після `npm run dev` її можна відкрити за адресою `http://127.0.0.1:5173/releases/arcade-0.2.1/`; архівна збірка не має нової вступної сцени.

## Керування

| Дія | Керування |
| --- | --- |
| Пропустити стартову сцену | Кнопка «Пропустити», Space або Enter |
| Рух ліворуч / праворуч | A / D або ← / → |
| Ривок у напрямку руху | Space під час польоту |
| Сповільнення світу за фокус | Утримувати Shift |
| Пауза / продовження | Escape або P |
| Рух мишею або пальцем | Перетягувати по ігровому полю |
| Сенсорне керування | Екранні кнопки руху, ривка та фокусу |
| Звук і зменшення руху | Кнопки інтерфейсу |
| Стиль приземлення | Перемикач у меню: аркада або жорсткий режим |

Ривок триває 0,28 с, захищає від захвату й відновлюється за 1,65 с. Завчасно обирай напрямок: стрілка показує його, а ривок фіксує на початку. Фокус сповільнює світ і таймер комбо.

Переслідувач стежить за траєкторією, фіксує ціль кораловим спалахом і коротким клацанням. Після спалаху змінюй курс. Бірюзові краплі відновлюють фокус; коралові дають більше фокусу й очок та продовжують комбо. Близькі прольоти, ризикові краплі та комбо підвищують оцінку стилю.

## Перевірки

```sh
npm test
npm run build
npm run test:browser
```

Браузерна перевірка самостійно піднімає тимчасовий Vite на порту 5174 і запускає встановлений Microsoft Edge через Playwright. Скриншоти та результати — у `artifacts/`.

Для ітерації 06 підтверджено 57 Node-тестів, включно з керуванням на 20/60/120 FPS, реакцією на видимі попередження із затримкою 150 мс, денними рекордами та життєвим циклом аудіо. Render suite містить 190 сценаріїв; фактичний стан build/browser/Pages-перевірок — у `docs/NEXT_SESSION.md`.
