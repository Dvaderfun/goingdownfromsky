# RAIN / PAIN

[Грати на GitHub Pages](https://dvaderfun.github.io/goingdownfromsky/) · [Аркада 0.2.1](https://dvaderfun.github.io/goingdownfromsky/releases/arcade-0.2.1/)

Нічна браузерна аркада на Three.js. Дівчина в жовтому дощовику летить уздовж фасаду, ухиляється від рук із вікон і збирає краплі. Кожен успіх відкриває вищу будівлю. Фінал:

> На вулиці rain — на душі pain

Версія 0.3.0 зберігає аркадну гру та додає окремий жорсткий фінал. У меню можна вибрати аркадний спалах із кільцями або ragdoll із кров’ю; аркада лишається початковим режимом. Вибір зберігається у браузері й фіксується на початку спроби. Колізії, прогресія та оцінки спільні для обох режимів.

Кожне небезпечне вікно належить одній видимій людині — з головою, торсом і двома анатомічно дзеркальними руками. Обидві руки діють разом і плавно повертаються у вікно після захвату. Стрибок із даху, рука-переслідувач, ризикові краплі, оцінки C / B / A / S та рекорди відкритих веж збережені.

## Запуск

Потрібні Node.js 20.19+ або 22.12+, npm і сучасний браузер із WebGL 2. Рекомендовано Chrome або Edge з апаратним прискоренням.

```sh
npm install
npm run dev
```

Відкрий адресу, яку надрукує Vite; зазвичай це `http://127.0.0.1:5173`. Гру слід відкривати через HTTP, а не подвійним кліком на `index.html`.

```sh
npm run build
npm run preview
```

Готова вебзбірка — у `dist/`. Звук починається після натискання ігрової кнопки. Загальний рекорд, рекорди й найкращі оцінки веж, відкритий рівень і налаштування зберігаються в цьому браузері. Збереження попередньої версії сумісні.

Попередню production-аркаду 0.2.1 збережено окремо. Після `npm run dev` її можна відкрити за адресою `http://127.0.0.1:5173/releases/arcade-0.2.1/`.

## Керування

| Дія | Керування |
| --- | --- |
| Рух ліворуч / праворуч | A / D або ← / → |
| Ривок у напрямку руху | Space |
| Сповільнення світу за фокус | Утримувати Shift |
| Пауза / продовження | Escape |
| Рух мишею або пальцем | Перетягувати по ігровому полю |
| Сенсорне керування | Екранні кнопки руху, ривка та фокусу |
| Звук і зменшення руху | Кнопки інтерфейсу |
| Стиль приземлення | Перемикач у меню: аркада або жорсткий режим |

Ривок триває 0,28 с і відновлюється за 1,65 с. Завчасно обирай напрямок: ривок використовує останній напрямок руху.

Переслідувач спершу стежить за траєкторією, потім фіксує ціль кораловим спалахом і коротким клацанням. Після спалаху змінюй курс. Бірюзові краплі відновлюють фокус; коралові дають більше фокусу й очок та продовжують комбо. Близькі прольоти, ризикові краплі та комбо підвищують оцінку стилю.

## Перевірки

```sh
npm test
npm run build
npm run test:browser
```

Браузерна перевірка самостійно піднімає тимчасовий Vite на порту 5174 і запускає встановлений Microsoft Edge через Playwright. Скриншоти та результати — у `artifacts/`.

`test:browser` включає `npm run test:render`: старт із даху, пару рук одного мешканця, tracking/lock/захват переслідувача, обидва види крапель, обидва стилі приземлення, фінал і зміну розміру. Для ітерації 04 звіт `artifacts/render-hard-landing-report.json` містить 154 стани, а `artifacts/render-hard-hard-landing-report.json` — 56 жорстких сценаріїв; обидва завершилися з `passed=true`, без помилок і невдалих перевірок. Перевіряються скінченні трансформації/прозорість, помилки WebGL, великі чорні області та сталість GPU-ресурсів.
